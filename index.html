02

Systems in service

Not a roadmap. Each of these exists, runs unattended, and has a failure mode we can name.

Scoring free-form human performance against a fixed rubric

Structured assessment engine

Takes a transcribed spoken answer and returns a typed scorecard: five named competencies on a 1–5 scale, estimated spoken duration, disqualifying red flags, line-by-line critique, and a rewritten model answer that demonstrates the target structure.

Python 3.14 · typed schemas · local speech-to-text

Raw source material to graded study artefacts

Three-node content pipeline

A directed pipeline that turns chapters and interview transcripts into a question bank, grades each item, then compiles the result into a flashcard deck, a reviewable dossier and a machine-readable manifest.

Typed node contracts · deterministic compiler · JSON manifest

Specification to upload-ready book

Publishing engine

A layout library that renders a book specification into a print-ready interior, a full cover wrap sized to the final page count, and a reflowable ebook — with no manual layout pass anywhere in the chain.

Vector PDF · EPUB3 · embedded subsetted fonts

Continuous surveillance with a zero-noise dispatch budget

Operations sentry

A resident daemon that watches live operational feeds, scores each event against encoded regulatory limits and a queue position, and dispatches only the events that are actionable today or tomorrow.

Resident poller · SQLite state · append-only dispatch log

Making a quantitative claim survive contact with evidence

Research harness

A verification layer that sits between a proposed result and anyone believing it. A claim is handed to a fresh-context reviewer with only the hypothesis, the script and the raw log, and comes back as VERIFIED, REFUTED or OVERFIT.

Clean-room review · fail-closed matrices · reproducible logs

The Interview-Ready Pilot: A Systematic Guide to the Airline Interview

The airline already believes you can fly. The interview decides whether they want to fly with you.

Built by a line pilot after failing an interview he was fully qualified for, then tested across seven airline interviews — US ultra-low-cost, US legacy and major international — with an offer from each.

The pilot programBuy the book

Why it belongs here

The book is the readable surface of an assessment engine. Behind it sits a scoring harness that grades a spoken answer against five named board competencies, measures its spoken length as arithmetic rather than opinion, and names the disqualifying failure modes. The product and the system are the same work.

04

How we work

  • A single operator with the right harness outperforms a team with the wrong one.

  • Model output is a hypothesis. Deterministic code is the verdict.

  • Anything that cannot be re-run and re-verified is not shipped.

Safety properties are never enforced at a layer too weak to hold them. Intent lives in a prompt; limits, arithmetic and guarantees live in deterministic code with a test around them.
