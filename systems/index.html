Systems

Five systems, and what each one refuses to guess.

Every system below is in service. For each one the interesting part is not what the model does — it is what has been taken away from the model and handed to code.

01

In service

Scoring free-form human performance against a fixed rubric

Structured assessment engine

Takes a transcribed spoken answer and returns a typed scorecard: five named competencies on a 1–5 scale, estimated spoken duration, disqualifying red flags, line-by-line critique, and a rewritten model answer that demonstrates the target structure.

  • Output is a schema, not prose — every field is validated before it is shown.
  • A separate pass rewrites a raw anecdote into a fixed proportional structure: context 20%, action 60%, result 20%.
  • Duration is computed from word count at measured speaking rate, so "too long" is arithmetic rather than opinion.

Python 3.14 · typed schemas · local speech-to-text

Raw source material to graded study artefacts

Three-node content pipeline

A directed pipeline that turns chapters and interview transcripts into a question bank, grades each item, then compiles the result into a flashcard deck, a reviewable dossier and a machine-readable manifest.

  • Node 1 runs a deterministic extraction pass first and only escalates to a model for what the pattern misses.
  • Node 2 is the only node allowed to reason; its output is schema-bound.
  • Node 3 contains no model calls at all, so the artefacts are byte-reproducible from the same manifest.

Typed node contracts · deterministic compiler · JSON manifest

Specification to upload-ready book

Publishing engine

A layout library that renders a book specification into a print-ready interior, a full cover wrap sized to the final page count, and a reflowable ebook — with no manual layout pass anywhere in the chain.

  • Store rejection rules as code: font embedding, gutter brackets, bleed and spine arithmetic are asserted, not remembered.
  • One engine, one house style, many titles — a fourteen-title catalogue reads as one imprint.
  • Re-running the generator after a content change recomputes the cover geometry automatically.

Vector PDF · EPUB3 · embedded subsetted fonts

Continuous surveillance with a zero-noise dispatch budget

Operations sentry

A resident daemon that watches live operational feeds, scores each event against encoded regulatory limits and a queue position, and dispatches only the events that are actionable today or tomorrow.

  • Contract and regulatory logic live in a data file with citations, not inside prompts.
  • Duty-limit headroom is bucketed into calibrated tiers, so an alert carries a reason and a threshold.
  • Every dispatch is written to an append-only log and marked seen only after the transport confirms delivery.
  • State is persisted with a time-to-live, so a restart never replays an alert.

Resident poller · SQLite state · append-only dispatch log

Making a quantitative claim survive contact with evidence

Research harness

A verification layer that sits between a proposed result and anyone believing it. A claim is handed to a fresh-context reviewer with only the hypothesis, the script and the raw log, and comes back as VERIFIED, REFUTED or OVERFIT.

  • The reviewer never sees the reasoning that produced the claim, so it cannot agree with it out of politeness.
  • Missing or unparseable inputs fail closed: no number is reported from a partial run.
  • This layer exists because it has already caught fabricated results that passed self-review.

Clean-room review · fail-closed matrices · reproducible logs

02

The common pattern

Different domains, same shape. This is the part that transfers.

  1. Deterministic first pass

    Anything a pattern can extract is extracted before a model is called. The model handles the remainder, not the whole input.

  2. Schema-bound reasoning

    Where judgement is genuinely needed, the output is a validated structure with named fields and ranges — never free prose that a later stage has to re-parse.

  3. Model-free compilation

    The final artefact is produced by plain code from the validated structure, so the same input reproduces the same output byte for byte.

  4. Fail closed

    A missing or unparseable input stops the run. No number is reported from a partial pass, and no alert is sent from a page that did not load.
